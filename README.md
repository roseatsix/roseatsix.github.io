# rose at six

A personal hub of everyday tools, hosted on GitHub Pages.

- `index.html` — the hub (main page)
- `assets/css/style.css` — shared styles; all colours are tokens at the top
- `assets/js/hub.js` — the tool list; add a tool by adding an entry to `TOOLS`
- `tools/<name>/` — each tool lives in its own folder (coming soon)
